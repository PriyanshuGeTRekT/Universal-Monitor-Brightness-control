How it works

Two threads, three ways to change brightness, nothing running in between.

UI thread

Tray icon, popup, keyboard shortcuts and dimming overlays. Sleeps in GetMessageW until you click or press a shortcut.

Worker thread

Talks to the displays. Sleeps in recv(). While you drag, only the newest value is sent.

HARDWARE

DDC/CI

External monitors over HDMI, DisplayPort or USB-C. VCP code 0x10 through dxva2.dll.

HARDWARE

WMI

Laptop and other built-in panels via WmiMonitorBrightnessMethods.

FALLBACK

Software dimming

Anything else: TVs, DisplayLink docks, DDC/CI turned off. A click-through overlay, hidden from screenshots.
